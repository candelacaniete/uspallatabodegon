# Uspallata Bodegón

Landing premium en Next.js para un restaurante inspirado en los bodegones porteños clásicos, con estética contemporánea, carta visual, reservas y acceso directo a WhatsApp.

La home usa App Router con render dinámico (`force-dynamic`) y una capa cliente para las interacciones de carta, navegación y reservas.

## Vista local

```bash
npm install
npm run dev
```

## Deploy en Vercel

- Framework Preset: `Next.js`
- Build Command: `npm run build`
- Output Directory: dejar vacío
- Install Command: `npm install`
